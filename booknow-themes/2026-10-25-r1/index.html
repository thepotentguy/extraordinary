Property identity should continue all the way to booking. These five themes begin with each official website’s mark, typography, colour and character, then translate it into the existing booking engine.

One design per property. Desktop and mobile. Review candidates awaiting Papi’s inspection.

What you are reviewing

Five locally built design candidates, using property-specific native booking markup and the packaged theme CSS. Click a preview to inspect it. Logos, photography and introduction copy are separate CMS items; installing only a theme will not produce the complete content shown here.

Checks and approval boundary

All five passed local viewport checks at 320, 390, 768, 1024 and 1440 pixels: no page overflow, loaded intended fonts and visible form fields at least 44 pixels high. Original native carousel behavior is retained. Each preview uses two crops of one photograph, solely to demonstrate that mechanism.

No live installation, availability search, booking or payment occurred. Physical-device behavior, each native booking journey and CMS acceptance still need an authorised installer. Existing map and accessibility findings remain open.
